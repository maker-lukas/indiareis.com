# indiareis.com
> A fun little website for my artistic sibling

![website](https://cdn.hackclub.com/01a1e09a-4749-785f-bac5-fcb9c3488999/Screenshot%202026-11-15%20at%2019-04-37%20Gallery.png)

My sibling has wanted a place where they can show off their drawings but they are not very technical and I am! So I offered to make it for them and I had this cool idea where we both can be involved where I basically code everything but they draw all assets on the website like buttons divs anything on actuall paper and then its going to be scaned and traced out and used as an asset!

check it out at [indiareis.pages.dev](https://indiareis.pages.dev/)

The artworks are realy old ones because its the only ones i had access right now but they still are good :3

**Features:**
- Filter by drawing style eg: Pencil, Ballpoint, etc
- CMS Sveltia image management system at /admin
- About page with self portrait and favorite gear (WIP)
- Hand drawn assets (only some started adding but realized the colors and some other stuff has to change so its kinda in the middle)
